Foundations

Two ladders drive the interface: a neutral background/text ladder that switches between light and dark, and a fixed-hue role/side/brand palette that's mode-invariant. Components should reference tokens by semantic name — never hex.

Principles

Information first. Reach for density before whitespace. FM users scan tables of tiny numbers for hours — this is a feature, not a flaw.
Mono for numerics. Any number the user compares across rows (OVR, credits, stats, salary, rank) uses the mono stack and tabular figures. Sans for prose.
Color carries meaning. Brand red is reserved. Role color identifies. Side color sets context on the match screen. Semantic colors signal state. Don't decorate.
Tokens, not hex. If you find yourself typing a color literal in a component, stop and add a token.
Dark works in daylight. Light mode isn't a second-class citizen — author against both simultaneously.
Accessibility is table-stakes. 4.5:1 contrast on text, 3:1 on non-text. Dot color is never the sole signifier — add a tooltip or label.
