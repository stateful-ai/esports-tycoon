# esports-tycoon — pinned dependency lockfile.
#
# The serialization toolchain has a byte-identity contract: ``dumps(load(week6.yaml))``
# must produce the same bytes on every checkout, every CPython, every CI run.
# That contract is only as strong as the install pin behind it — a quietly-resolved
# ``PyYAML==6.0.2`` could re-pad a scientific-notation mantissa, ``pydantic==2.14``
# could reorder a model's serialized fields, and the committed canonical golden
# (``tests/golden/week6_canonical.yaml``) would drift on a clean install with no
# source change at all.
#
# This file is the install-time pin that anchors the contract. ``make install``
# runs ``pip install -c constraints.txt -e .[dev,web]``; CI does the same. Every
# version below was the one used to bless the committed goldens; bump them only
# alongside a reviewed re-emission of those goldens.
#
# Python minor is pinned separately in ``pyproject.toml`` (``requires-python = ">=3.12,<3.13"``)
# — pip can't constrain the interpreter, only the packages it installs.
