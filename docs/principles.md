# Principles

## Determinism over richness
We prefer fewer, reliably-reproducible adaptive moves over richer
content that drifts run-to-run.

## Templates first
Prose lives in templates by default. Each LLM call needs a justification.

## Single-concern PRs
Each PR moves one thing forward; bundled diffs hide regressions.

## Numbers carry weight
In game text, numbers and named entities do more work than adjectives.

## Save the surprise
The tycoon experience is in noticing the system's reactions, not in being
told about them. Resist the urge to explain.
