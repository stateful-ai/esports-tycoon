# Glossary

- **Tycoon loop** — draft, train, schedule matches, react to outcomes, repeat.
- **Chirper** — the in-game social-media feed; text generated via the content adapter.
- **Content adapter** — the seam between the deterministic sim and LLM-backed prose generation.
- **Halftime ack** — the narration beat between halves of a match.
- **Templated default** — the cheap, deterministic content path; the LLM backend is opt-in.

Add new terms here as the team converges on vocabulary.
